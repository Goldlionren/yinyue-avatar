# v0.2.3 release and recovery notes

v0.2.3 imports the exact code, workflow, persona, and role history used by the
2026-07-28 production installation. It does not add long-term-memory or scene
state-machine behavior.

The private `config.local.json` is intentionally not tracked or included in the
source release. Copy `config.local.example.json` and set machine-local ComfyUI,
Telegram, and state paths. The production workflow masked hash is already the
default. Python 3.10+ and the Hermes CLI are required; the Python implementation
uses only the standard library. ComfyUI must provide the models, LoRAs, and
custom nodes referenced by the workflow.

The full recovery archive is the disaster-recovery authority. Extract it in a
private directory, verify `MANIFEST_SHA256.txt`, review the bundled restoration
script in dry-run mode, and use `--apply` only after confirming target paths.
Restoration never starts generation, workers, ComfyUI jobs, or Telegram sends.

Rollback from later development means checking out annotated tag `v0.2.3` for
source, or using the full recovery archive for an exact production-and-state
restore. State formats introduced later must retain v0.2.3 reading and backup
rollback paths.
