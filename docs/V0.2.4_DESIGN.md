# v0.2.4 design

v0.2.4 adds two cooperating systems without changing the authoritative
production workflow: layered role memory and a deterministic scene state
machine. The old `visual`, `internal`, and `continuity` surfaces remain readable
and writable for v0.2.3 callers.

Runtime context is `persona + lore summary + relationship + current
scene/emotion + deterministic long-term summary + bounded meaningful recent
events`. It never loads the complete memory event store or whole history file.
Image prompts continue to use the deterministic
visual serializer and never receive relationship prose, full lore, memory
summary, or history.

Agents extract only a high-level transition type and ordered actions.
`state_v024.apply_transition()` validates a strict allowlist, copies the current
state, applies fixed rules, verifies relationship and memory are unchanged, and
returns a validated candidate. `transition --render` passes that candidate
through the existing generation transaction; only successful image generation
commits state and history.

The production workflow, fixed prompts, node 63 prompt injection, node 85 seed
injection, text-before-media delivery, queueing, deduplication, exit codes, and
pending-delivery behavior remain protected by the v0.2.3 baseline.
